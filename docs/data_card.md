# Data Card -- MANGAN-AI

## Data currently in this repo
| Dataset | Path | Real or synthetic | Notes |
|---|---|---|---|
| Public-fallback prospectivity features | `data/prospectivity/raw/`, `data/prospectivity/verified/` | **Synthetic** | Generated by `pipelines/geospatial/gee_extraction.py` because this build environment has no internet/GEE access. Schema-identical to what Team 1's real extraction will produce. |
| Demo scenario data | `scenarios/*.json` | **Synthetic** | One coherent fictional mine story used by all six DEMO models. |

## Data NOT yet in this repo (pending other teams / real deployment)
- Team 1's real Sentinel-2/DEM/geological extraction (Parquet, per `schemas/ingestion_contracts/team1_parquet_schema.json`)
- Team 2's verification/leakage/duplicate audit output (per `schemas/ingestion_contracts/team2_verified_schema.json`)
- Any real MOIL operational data (production logs, equipment maintenance history, assay/grade records, weather history)

## Rule this repo follows
Public data -> used for the MVP's LIVE model.
MOIL data -> future calibration/deployment, not yet present.
Synthetic data -> software/workflow demonstration ONLY, never presented as MOIL or real-world accuracy evidence.
